# 通し実行報告: Lantern Guild Season

- 入力: `examples/lantern_guild_season/`（3パーティー、5地域、シード 20261001）。シーズンは掲示板が空いたためGMが11ターンに延長した
- 範囲: 開幕ドラフト → ターン1〜11（ターン5に中盤ドラフト）→ シーズン終了 → `finalize_session.ts`
- 実施方法: パーティーごとに別のサブエージェントを立て、全ターン同じエージェントを継続した。各エージェントが読めるのは自分のリクエストファイルとルール文書だけで、GMと進行は1つのエージェントが担当した
- 記録: `playlog.jsonl`（13エントリ）、`world_final.json`、`narrative_replay.md`

## 結果

| パーティー | 評判 | 達成した依頼 |
|---|---|---|
| 銀羽根団（昇格） | 7 | トンネル地図、帳簿の買い手、病んだヴェルの救出 |
| 鉄狼団 | 6 | ヴェル護送、オラの船の差し押さえ |

依頼の決着は達成6、衝突による失敗3、期限切れ1（共同依頼の墓所封印）。疫病クロックは満了し、旧市街が隔離された。密輸団クロックは船の差し押さえで0に戻った。

## 機能した点

- **依頼の衝突は4回起きた。どれも依頼の構造から生まれ、GMの仕込みではない**
  - 護送と口封じ（ターン2〜3）
  - 証拠箱の奪還と帳簿をオラへ（ターン5〜8）
  - 船の差し押さえと船の脱出（ターン10）
  - ヴェルの救出に3組が殺到（ターン11）
- **3つの欠点がすべて筋を動かした**
  - 灰灯団（欲）: 地図の依頼を捨てて口封じに寝返った
  - 銀羽根団（好奇心）: 中盤ドラフトで、必要な隠れ場所の情報ではなく判事の弱みを買った
  - 鉄狼団（誇り）: 共同依頼の申し出を2度断り、封印は期限切れになった
- **失敗と部分成功が筋になった**: 鉄狼団は傷だらけで護送を果たしたが、届けたヴェルが証拠を盗んだ。この秘密はターン1に判明していたのに、依頼は止められなかった。それが後半の筋の起点になった
- **情報は分離できた**: パーティーごとに別のエージェントにしたことで、パイロットで起きた漏洩（他パーティーの知識を判断に使う）は観測されなかった。ただし、エージェントがルールどおりリクエストファイルだけを読んだかは自己申告でしか確認できない
- **終盤に密度が落ちなかった**: 既存リプレイで見られた終盤の効果数の減衰はなかった。最終ターンは3組が同じ依頼に集まり、季節で最も密度の高い場面になった

## 設計上の課題

1. **対抗判定が少なく、決着戦が一度も起きなかった**
   - 2回目の衝突以降、灰灯団は2度（ターン8、ターン10）明示的に3回目を避け、並走して進捗を競った
   - 妨害は-1に上限があり、負ければ状態を負う。進捗を自分に積む方が期待値で勝る
   - 決着戦は膠着を断つ仕組みとしてより、抑止として働いた
   - 案: 同じ依頼の場所にいる競合相手が進捗判定をしたら、対抗判定で割り込めるようにする（受け身の妨害）
2. **掲示板が空になるターンがある（ターン4、ターン9）**
   - GMはパーティーと同時に行動するので、GMが出した依頼は次のターンにしか見えない。休息7回のうち多くはこの空白に重なる
   - 案: アップキープでGMの依頼発行を先に処理する。または、依頼が終わりそうなら1ターン前に補充するようGM_CORE_MINDに書く
3. **最終ターンに代償の地平線効果が出た**
   - 「最後なので行動不能になってもよい」と、2組が状態を代償に選んだ
   - 案: シーズン終了時に残った状態を評判の同点判定に使う。または、次のシーズンに持ち越す
4. **下位の一行が勝者を決めた**
   - 灰灯団は自分の依頼を持たず、銀羽根団の進捗を2つの判定で積んだ（+3）。助力がなければ、銀羽根団と鉄狼団はともに進捗2で並び、決着はダイスに委ねられていた
   - 物語としては強い結末だが、他者の進捗に書き込めるため、談合も許す
   - 案: 助力を残すなら、助力した側にも関係値以外の見返りを与えて動機を明示する（共同依頼の報酬按分に近い扱い）。禁止するなら、進捗の書き込みを自分のものに限る
5. **首位への共同依頼は、下位にとって魅力がない**
   - 封印の依頼（評判4、働きに応じて按分）は、首位の銀羽根団が5/5を一組で終えたまま期限切れになった
   - 首位を伸ばす協力は、競争の上では損になる
   - 案: 共同依頼の失敗に全員が負う結果（クロック進行など）を付ける。または、参加者全員に報酬を満額渡す
6. **ターン10の処理記録を一度失った**
   - `append_playlog.ts`の引数を誤って失敗したまま`generate_next_turn.ts`を実行し、応答ファイルが削除された。会話記録と`checkLog`から復元した
   - 対策として、プレイログ未記録の処理済み応答があれば`generate_next_turn.ts`が停止するようにした
   - あわせて、`finalize_session.ts`がプレイログのステップ数を最終ターンとして記録していた不具合も直した

## 通し実行中に修正した不具合

- 秘密を持たない依頼を調べるとクラッシュした → 秘密の既定値を補う
- 雇われなかった雇い人の効果で、クロックが-1になった → クロックを0で下止めする
- リクエストに人物設定、地域の隣接、ドラフト中の知識、関係値がなかった → 追加した
- 両立しない依頼が同時に達成されると、結果がファイル順に依存した → 余裕の大きさとダイスで決める
- 存在しない`knowledge`への追加が、配列ではなく生のオブジェクトになった → 配列に正規化する
- 移動してから判定する手順が文書になかった → 明記した
